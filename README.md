# Neighbor · Terra Lugo

Prototipo web inicial de Neighbor para Terra Lugo, Cupey Bajo.

## Archivos

- `index.html`: estructura principal.
- `styles.css`: diseño responsive, modo claro y oscuro.
- `app.js`: tarjetas, actividad reciente e interacciones.

## Publicar en GitHub Pages

1. Crea un repositorio llamado `neighbor-terra-lugo`.
2. Sube estos cuatro archivos a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y la carpeta `/root`.
6. Guarda los cambios.
